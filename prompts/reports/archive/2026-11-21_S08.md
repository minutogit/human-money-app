## 3. Open Uncertainties / Design Questions (`S08-Q1`–`S08-Q4` All Resolved)

1. **`S08-Q1` (RESOLVED) — `reqwest` `system-proxy` Bypass of `SsrfSafeDnsResolver` (`src-tauri/src/sync_client.rs`):**
   - Disabled OS/environment HTTP proxies via `.no_proxy()` on both `create_sync_http_client()` and `create_sync_probe_client()` (with unit regression coverage in `s08_q1_sync_clients_disable_proxies_and_block_ssrf_targets`), guaranteeing `HTTP_PROXY`/`HTTPS_PROXY` cannot bypass `SsrfSafeDnsResolver` (corporate networks restricting egress should allow direct HTTPS to Sync hosts).
2. **`S08-Q2` (RESOLVED) — `HUMOCO_ALLOW_LOOPBACK_SYNC=1` Active in Release Builds (`src-tauri/src/sync_client.rs`):**
   - Restricted `loopback_sync_allowed()` to `cfg!(test) || (cfg!(debug_assertions) && env == "1")`; release builds unconditionally disallow env-var loopback/HTTP SSRF downgrades.
3. **`S08-Q3` (RESOLVED) — Per-Origin 429 Cooldown (`src-tauri/src/{sync_client,state}.rs`, `sync_coordinator.rs`, `backup_service.rs`, `post_service/`, `sync_engine/`):**
   - Replaced global `SyncCoordinatorControl.cooldown_until` with bounded per-origin `origin_cooldowns` keyed by canonical `sync_origin_key(url)`, preventing one throttled/malicious contact sync server from blocking own off-site backups, PoST, or other hosts.
4. **`S08-Q4` (RESOLVED) — `save_sync_setup_zip` Arbitrary-Path Write Bypassing Tauri `fs` Scope + Dead `zip_base64` (`HostSyncSetupWizard.tsx`, `commands/sync.rs`, `sync_engine/admin.rs`):**
   - Removed `save_sync_setup_zip` (`S08-R4`) and updated `HostSyncSetupWizard.tsx` to decode `draft.zipBase64` and persist via `saveBytesToFile` strictly inside Tauri's dialog `fs` scope.
